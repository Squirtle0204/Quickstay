
# 🏠 Quickstay

A full-stack accommodation booking platform inspired by Airbnb, built using Next.js and modern web technologies.

## 🚀 Live Demo

**[View Quickstay Live →](https://quickstay-seven-taupe.vercel.app)**

## ✨ Features

- 🔐 Secure user authentication
- 🏠 Browse accommodation listings
- 🔎 Explore property details
- 📅 Date-based booking
- ❤️ Favorite properties
- 👤 User account management
- 📸 Cloudinary image uploads
- 🗄️ PostgreSQL database
- 📱 Responsive design

## 🛠️ Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Styling:** Tailwind CSS
- **Authentication:** Better Auth
- **Database:** PostgreSQL
- **ORM:** Prisma
- **Image Storage:** Cloudinary
- **HTTP Client:** Axios
- **Date Picker:** React Date Range
- **Deployment:** Vercel
